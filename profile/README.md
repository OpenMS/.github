# Welcome to @OpenMS!

@OpenMS is an open-source C++ software library for LC-MS data management and analysis with python wrappers ([pyOpenMS](https://github.com/OpenMS/OpenMS/tree/develop/src/pyOpenMS)), a large modular toolset and workflows for e.g., Galaxy, KNIME and nextflow.

Here's how to get started:

- 📚 Browse through the main library and pyOpenMS code under [OpenMS/OpenMS](https://github.com/OpenMS/OpenMS)
- 👩‍💻 Check out the [documentation](https://www.openms.de/documentation).
- 🙋‍♀️ Come and say hi on our [Discord](https://discord.gg/wcWETcAkvS)!
- 🍿 Tune in for news about developer/user meetings and events, get involved!
- 🌈 Please abide by [our community code of conduct](https://github.com/OpenMS/OpenMS/blob/develop/CODE_OF_CONDUCT.md)
